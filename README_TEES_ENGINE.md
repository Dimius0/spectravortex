# TEES Knowledge Engine v4.2

**Извлечение знаний из текстов без семантики, без нейросетей, без Гаусса.**

Только ВММП (Вихревая Модель Материи-Пространства), топологические заряды и ∇⁴ψ = 0.

## Что делает

- Парсит тексты (русский / английский)
- Извлекает TEES-связи (SOURCE → TEES → RECEIVER)
- Проверяет каждую связь на согласованность с ВММП
- Строит граф знаний
- Генерирует новые гипотезы (фуркации)
