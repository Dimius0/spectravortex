МОДУЛИ РИЗОМЫ-2: НАЗНАЧЕНИЕ И НАУЧНАЯ ИНТЕРПРЕТАЦИЯ
1. ЯДРО (CORE)
1.1 Synchronizer (Синхронизатор)
Назначение: Задаёт глобальный ритм системы, синхронизирует работу всех модулей.

Научная интерпретация:

Математически: Генератор временной шкалы с обратной связью. Реализует дискретизацию времени с адаптивным шагом. period = 1.0 / base_frequency + phase_correction — аналог регулятора с фазовой автоподстройкой частоты (ФАПЧ).

Физически: Аналог абсолютного времени в классической механике или собственного времени в релятивистских моделях. Обеспечивает причинность и последовательность событий.

1.2 PhasePredictor (Предсказатель фаз)
Назначение: Анализирует историю, предсказывает "окна возможностей" для эффективных действий.

Научная интерпретация:

Математически: Анализ временных рядов. Вычисляет стабильность фазы как 1 - std(phase_diffs). Использует скользящее окно для локального прогноза.

Физически: Аналог принципа наименьшего действия — система ищет траектории (моменты времени), где действие (удар) будет наиболее эффективно.

1.3 AnomalyBuffer (Буфер аномалий)
Назначение: Хранит обнаруженные аномалии, управляет их приоритетами, превращает в цели.

Научная интерпретация:

Математически: Очередь с приоритетами. Реализует функцию ценности: priority = power * (decay ** age) + hit_count * 0.1. Использует динамическое программирование для вытеснения.

Физически: Аналог фазового пространства системы. Каждая аномалия — точка в пространстве состояний. Буфер хранит наиболее вероятные траектории эволюции.

2. РАЗВЕДЧИКИ (SCOUTS)
2.1 LightScout (Лёгкий разведчик)
Назначение: Быстрое сканирование ближней зоны, первичное обнаружение.

Научная интерпретация:

Математически: Стохастический зондаж с низкой точностью. Вероятность обнаружения: P = precision * (1 - distance/200).

Физически: Аналог слабой локализации или квантового измерения с низкой энергией. Не возмущает среду, но и даёт мало информации.

2.2 MediumScout (Средний разведчик)
Назначение: Подтверждение и уточнение найденных аномалий.

Научная интерпретация:

Математически: Итеративное уточнение. Работает каждый 2-й такт — аналог метода половинного деления во времени.

Физически: Аналог резонансного зондирования — настраивается на частоту уже обнаруженного сигнала.

2.3 HeavyScout (Тяжёлый разведчик)
Назначение: Детальный анализ подтверждённых целей, добивание.

Научная интерпретация:

Математически: Высокоточный, но ресурсоёмкий. Работает каждый 3-й такт. precision = 0.95.

Физически: Аналог сильного взаимодействия — включается только когда нужно "схватить" цель.

3. КОРРЕКТИРОВЩИКИ (SPOTTERS)
3.1 Spotter (Корректировщик)
Назначение: Разведчик в режиме целеуказания. Удерживает захват цели, даёт поправку пульсу.

Научная интерпретация:

Математически: Реализует метод градиентного спуска по координатам цели. lock_quality — аналог нормы градиента.

Физически: Аналог принципа неопределённости Гейзенберга в действии — чем точнее знаем положение цели (lock_quality), тем меньше можем влиять на неё (confidence).

3.2 SpotterManager (Управление корректировщиками)
Назначение: Распределяет корректировщиков по целям.

Научная интерпретация:

Математически: Задача о назначениях (assignment problem). Решается жадным алгоритмом — "самому сильному корректировщику — самую жирную цель".

Физически: Аналог принципа запрета Паули — два корректировщика не могут сидеть на одной цели (если только не спарены).

4. ПУЛЬС (PULSE)
4.1 PulseHunter (Охотник пульса)
Назначение: Наносит удары по целям в оптимальной фазе.

Научная интерпретация:

Математически: Адаптивный регулятор. charge = phase_energy + target_energy + ref_energy + spot_energy. Вероятность успеха — сигмоида от заряда.

Физически: Аналог вынужденных колебаний — бьёт с частотой, близкой к резонансной для цели.

4.2 ReferencePoint (Реперная точка)
Назначение: Точки с известными свойствами (координаты 1000), служат для калибровки.

Научная интерпретация:

Математически: Базисные векторы в пространстве параметров.

Физически: Аналог фундаментальных констант (масса покоя, заряд) — точки отсчёта, относительно которых измеряется всё остальное.

5. ШУМОДАВ (FILTER)
5.1 NoiseFilter (Фильтр шума)
Назначение: Отсеивает ложные срабатывания разведчиков.

Научная интерпретация:

Математически: Медианный фильтр с памятью. Усредняет историю сигналов от конкретного разведчика: if avg < threshold: reject.

Физически: Аналог термодинамического равновесия — флуктуации ниже определённого уровня считаются тепловым шумом и игнорируются.

6. ИНСПЕКТОРЫ (INSPECTORS)
6.1 Inspector (Инспектор)
Назначение: Чистит устаревшие и бесполезные аномалии, превращает их в паттерны.

Научная интерпретация:

Математически: Кластеризация и сжатие данных. Вычисляет score = power*0.4 + age*0.3 + hit_count*0.2 + target_bonus*0.1. Удаляет с score < 0.3.

Физически: Аналог второго начала термодинамики — стремится увеличить энтропию (удалить лишнее), но оставляет "ценные" структуры (цели).

7. КЛОНЫ (CLONES)
7.1 Clone (Клон)
Назначение: Резервная копия системы, готовая подхватить управление при коллапсе основной.

Научная интерпретация:

Математически: Распределённое состояние. heartbeat_history — аналог контрольных сумм.

Физически: Аналог квантовой запутанности — клон знает состояние оригинала без прямого измерения (через heartbeat).

7.2 CloneSwarm (Рой клонов)
Назначение: Управление множеством клонов, выбор преемника.

Научная интерпретация:

Математически: Теория голосования. Выбирает клона с максимальным last_sync_tick — аналог консенсуса в распределённых системах.

Физически: Аналог принципа суперпозиции — пока оригинал жив, клоны существуют как потенциальные состояния.

8. МЕТРИКИ (METRICS)
8.1 MetricsCollector (Сборщик метрик)
Назначение: Собирает статистику работы системы, вычисляет производные показатели.

Научная интерпретация:

Математически: Многомерный статистический анализ. Вычисляет скользящие средние, дисперсии, корреляции.

Физически: Аналог измерительного прибора в эксперименте. Наблюдает, но не вмешивается (когда работает правильно).

8.2 SystemMetrics (Метрики системы)
Назначение: Структура данных, содержащая текущие показатели.

Научная интерпретация:

Математически: Вектор состояния в пространстве параметров.

Физически: Аналог волновой функции — полное описание системы в данный момент времени.

9. АДАПТИВНЫЕ МЕХАНИЗМЫ
9.1 Adaptive Cooldown (Адаптивная перезарядка)
Назначение: Меняет частоту пульса в зависимости от эффективности.

Научная интерпретация:

Математически: Пропорциональный регулятор. if efficiency > 0.8: cooldown -= 0.2; if < 0.5: cooldown += 0.2.

Физически: Аналог отрицательной обратной связи в кибернетике — система стремится к гомеостазу.

9.2 Adaptive Buffer (Адаптивный буфер)
Назначение: Меняет ёмкость и пороги буфера под нагрузку.

Научная интерпретация:

Математически: Адаптивный размер окна. if fill_ratio > 0.9 and efficiency > 0.9: capacity += 100.
