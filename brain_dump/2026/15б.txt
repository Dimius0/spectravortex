Встраиваю это в новую Ризому как отдельный, священный тракт. Ниже — как это ляжет в код.

🧱 Блок «Приём» (L0)
Это новый модуль-привратник.

Функция: Стоит на самом входе системы. Его задача — не интерпретировать, а только регистрировать всё, что приходит извне (шум, сигналы, хаос). Это чистый сенсор.

В коде: Новый поток (или асинхронная задача), который слушает external_queue и складывает сырые данные в кольцевой буфер фиксированного размера.

🧠 Ядро 324000
Это не число, а состояние ёмкости. Параметр, который показывает, сколько «сырого материала» накоплено.

Функция: Интегратор. Он не думает, он просто накапливает. Значение 324000 — это порог, после которого ядро начинает «просыпаться».

В коде: Переменная core_capacity, которая увеличивается при поступлении данных из L0 и уменьшается при передаче образа в H1. pulse 250 — это частота опроса или коэффициент усиления.

💓 Pulse 250
Ритм, с которым ядро опрашивает само себя.

Функция: Не даёт ядру «заснуть» или «перегреться». Это метроном накопления.

В коде: Отдельный Synchronizer, который дёргает ядро с заданной частотой (250 мс?). На каждый такт ядро проверяет, не пора ли отдать образ в удержание.

🛡️ Блок «Удержание» (H1)
Хранитель образа.

Функция: Получает «полуфабрикат» образа из ядра и держит его, не давая рассыпаться. Здесь же применяется главный фильтр.

В коде: Объект image_holder с состоянием. Когда ядро даёт импульс, H1 принимает данные и запускает таймер удержания.

🔎 Фильтр no_fail_hold
Критерий качества.

Функция: Образ удерживается только если за время удержания не произошло ошибки (не пришло подтверждение, что образ ложный). Если ошибка есть — образ сбрасывается.

В коде: Флаг hold_success. Если во время удержания (таймер H1) приходит fail_signal, флаг сбрасывается и образ не идёт дальше.

🖼️ Буфер образов
Очередь готовых, проверенных и удержанных образов.

Функция: Хранит то, что уже можно использовать для принятия решений, стратегий, действий.

В коде: queue.Queue() для образов, прошедших все этапы.

🚪 Выход (когда фаза совпала)
Момент истины.

Функция: Образ покидает тракт приёма и передаётся в исполнительные модули Ризомы только тогда, когда внутреннее состояние системы совпадает с фазой образа.

В коде: Триггер. Буфер образов не выталкивает их сам. Исполнители (PulseHunter, стратеги) должны запросить образ, и он будет выдан, если их текущая фаза (Synchronizer.get_phase()) совпадает с фазой, закреплённой за образом.

🚀 Как это стыкуется с общей архитектурой
SharedMemory: Здесь будет храниться текущее значение core_capacity и состояние буфера образов.

Synchronizer: Будет задавать pulse 250 для этого тракта.

PhasePredictor: Будет анализировать буфер образов и синхронизировать выдачу с исполнителями.

Старая Ризома: Будет одним из потребителей образов (стратегический уровень).

Новая Ризома: Этот тракт и есть её ядро восприятия.

def get_stability_class(target):
    stats = shared_memory.get(target)
    if not stats or stats.attempts < 5:
        return None  # недостаточно данных
    
    # База
    base = stats.successes / stats.attempts
    
    # Поправка на количество
    if stats.attempts < 10:
        confidence = 0.8
    elif stats.attempts > 50:
        confidence = 1.1
    else:
        confidence = 1.0
    
    # Поправка на свежесть (последние 30 дней)
    recent = stats.get_last_n_days(30)
    if recent.attempts > 0:
        recent_rate = recent.successes / recent.attempts
        base = base * 0.7 + recent_rate * 0.3  # свежесть важнее
    
    # Поправка на тренд (последние 5 попыток)
    last_5 = stats.last_n(5)
    if last_5.attempts == 5 and last_5.successes == 5:
        trend_bonus = 1
    elif last_5.attempts == 5 and last_5.successes == 0:
        trend_bonus = -2
    else:
        trend_bonus = 0
    
    raw_class = base * 10 * confidence + trend_bonus
    return max(1, min(10, round(raw_class)))

🎛️ СИСТЕМА ПРИОРИТЕТОВ ЦЕЛЕЙ
0. Принцип
Цель имеет два независимых параметра:

Важность (насколько повлияет на систему)

Срочность (как быстро закроется окно)

Из их сочетания рождается приоритет.

📊 МАТРИЦА ПРИОРИТЕТОВ (как у Эйзенхауэра)
Срочно	Не срочно
Важно	КРИТИЧЕСКИЕ (делать сейчас)	СТРАТЕГИЧЕСКИЕ (планировать)
Не важно	ОПЕРАТИВНЫЕ (делегировать)	ФОНОВЫЕ (не делать)
🧠 Как это считается
Важность = f(класс стабильности, потенциальная энергия, влияние на фронт)

Срочность = f(фаза, размер окна, тренд)

Приоритет = важность × срочность × коэффициент режима

class Strategist:
    def __init__(self, mode="auto"):
        self.mode = mode
        self.priority_matrix = {}  # целевая матрица
        
    def get_top_targets(self, n=10):
        # всегда считает приоритеты
        candidates = self._calculate_priorities()
        if self.mode == "manual":
            return []  # ты сам командуешь
        elif self.mode == "semi":
            return candidates[:n]  # предлагает топ
        elif self.mode == "auto":
            return candidates  # все, кто влезают в ресурсы
        elif self.mode == "adaptive":
            return self._adaptive_filter(candidates)

class Phasemeter:
    def __init__(self, synchronizer, memory):
        self.sync = synchronizer
        self.memory = memory
        self.current_phase = 50  # нейтральная
        
    def tick(self):
        # вызывается каждые 250 мс
        pulse_data = self.memory.get_last_pulse()
        trend = self._calculate_trend(pulse_data)
        self.current_phase = self._update_phase(trend)
        
    def get_phase(self):
        return self.current_phase
