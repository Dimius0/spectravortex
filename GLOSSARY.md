## Глоссарий ВММП: Птичий → Наукообразный (и Обратно)

**Статус:** Официальный словарь-переводчик терминов проекта SpectraVortex. 
**Цель:** Устранить терминологический барьер между Вихревой Моделью Материи-Пространства и стандартной физико-химической литературой.

### Фундаментальные Принципы
| ВММП (Птичий) | Наукообразный (Общепринятый) | Краткое Пояснение |
| :--- | :--- | :--- |
| Поле H | Сверхтекучий квантовый конденсат, физический вакуум | Среда, колебаниями и дефектами которой является всё сущее. Не эфир. |
| Вихрь | Топологический дефект, солитон, узел | Устойчивое, замкнутое движение в Поле H. Атом, частица, ядро. |
| Квантор (Qnt, Z=0) | Квант взаимодействия, калибровочный бозон | Акт когерентности. Не частица, а процесс передачи действия. Единство Причины и Следствия. |
| Приталкивание | Гравитация, эффект Казимира (макро) | Внешнее давление поля H на вихревые структуры. Не притяжение масс. |
| Монизм | Единая теория поля | Существует только движение. Всё остальное — его проявления. |

### Структура Материи
| ВММП (Птичий) | Наукообразный (Общепринятый) | Краткое Пояснение |
| :--- | :--- | :--- |
| Ступенька (d_min) | Устойчивое состояние, минимум энергии | Равновесное межатомное расстояние в ансамбле. Аналог минимума энтальпии. |
| Лестница к Аттрактору | Каскад фазовых переходов, релаксация | Пошаговый сброс энергии системой к глобальному минимуму. |
| Распорка | Метастабильное состояние, локальный минимум | Состояние с повышенной энергией, где система «застревает» перед следующим сбросом. |
| Спящая Распорка | Кинетически стабилизированная фаза | Долгоживущее метастабильное состояние, требующее «пинка» для выхода. |

### Взаимодействия и Связи
| ВММП (Птичий) | Наукообразный (Общепринятый) | Краткое Пояснение |
| :--- | :--- | :--- |
| Резонанс («спелись») | Когерентность, синхронизация | Состояние, когда два вихря колеблются на одной частоте. Условие для образования связи. |
| Химическая связь | Установившийся резонансный обмен Кванторами | Не палочка, а непрерывный поток квантов действия между атомами. |
| Пухляш | Когерентный димер/кластер, неравновесный комплекс | Временная, резонансная связь между элементами (например, Ne-Ar-O). |
| Кооперативная стабилизация | Коллективная стабилизация | Тяжелый элемент «помогает» удержать легкий в неравновесной связи. |

### Методы Воздействия и Синтеза
| ВММП (Птичий) | Наукообразный (Общепринятый) | Краткое Пояснение |
| :--- | :--- | :--- |
| Укол / Пендель | Импульсное воздействие, накачка | Резкое изменение P/T для нарушения «Распорки». |
| Заморозка | Закалка, фиксация неравновесного состояния | Быстрое охлаждение для стабилизации метастабильной фазы. |
| Серия импульсов | Параметрический резонанс | Раскачка системы на собственной частоте для управляемого фазового перехода. |
| Метод Пересечения Траекторий | Динамический синтез | Синтез соединений в момент резонанса элементов, а не при статических P и T. |
| Топологическое сродство | Химическое сродство | Совместимость элементов по «ступенькам» (d_min) для образования связи. |

### Эффекты и Наблюдения
| ВММП (Птичий) | Наукообразный (Общепринятый) | Краткое Пояснение |
| :--- | :--- | :--- |
| Эффект Бабочки | Чувствительность к начальным условиям | Минимальный «Укол» кардинально меняет траекторию релаксации системы. |
| Дыхание Вселенной | Осцилляции красного смещения | Предсказанные ВММП колебания (~12 дней) метрики поля H. |
| Дрожание | Флуктуации метрики | Микроскопические проявления «Дыхания Вселенной». |
| Фрактальное время | Эмерджентное время, масштабная инвариантность | Разный темп эволюции для разных масштабных уровней (ядро vs молекула). |
| Кластерная теория газов | Неидеальная газовая динамика | Газ — не набор частиц, а пена из короткоживущих вихревых ансамблей. |

### Инструментарий
| ВММП (Птичий) | Наукообразный (Общепринятый) | Краткое Пояснение |
| :--- | :--- | :--- |
| Оракул | Предиктивная аналитика | Модуль прогнозирования продуктов синтеза на основе текущих d_min. |
| ДБР-Реактор | Диэлектрический барьерный разряд | Лабораторная установка для верификации предсказаний модели. |
| Алхимический Реактор | Виртуальный симулятор синтеза | Интерфейс для ручного выбора элементов и получения прогноза их соединения. |
| Ковчег (Копилка) | Репозиторий, база знаний | GitHub проекта, содержащий код, данные и документацию. |
| Железный Конь | Вычислительная машина | ПК или сервер, на котором проводятся расчеты. |
