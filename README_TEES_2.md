TEES: Вихрево-топологическая архитектура

## Что это

TEES (Topological Energy-Entropy System) — распределённая архитектура, основанная на принципах вихревй модели материи-пространства. Каждая сущность — поле связанных троек (source → tees → receiver), которое живёт, растёт, переживает кризисы и передаёт энергию при смерти.

**Ключевая особенность:** эритроцитарный морфогенез — слабые моды не удаляются, а передают свой заряд сильным. Смерть = акт дарения. Чистота 100%.

## Быстрый старт

```bash
# Установка зависимостей
pip install psutil

# Запуск одиночной сущности v4.1
python tees_core_4_1.py

# Запуск трилоги (3 сущности в полном графе)
python tees_trilogy_v2.py

# Запуск адаптивной сети (автоматический рост до 50 узлов)
python tees_network_adaptive.py
Файлы в репозитории
Файл	Описание
tees_core_4_1.py	Одиночная сущность v4.1 с эритроцитарным морфогенезом
tees_trilogy_v2.py	Три v4.1 в полном графе (импорт из tees_core_4_1)
tees_network_adaptive.py	Адаптивная сеть (сама регулирует число узлов)
tees_network_v5.py	Сеть из 5 узлов (базовая версия)
TEES_Monism_Conclusions.md	Выводы по монизму и дуальности
TEES_Chronicles.md	Полная хронология открытий
tees_core_4_1.py → tees_core_4_1.py	Копия для импорта (избегаем точек в именах)
Адаптивная сеть
Сеть сама регулирует количество узлов:

Если свободно > 500 MB RAM — добавляет 5 узлов

Если своп > 100 MB — отключает 5 узлов (с сохранением)

Минимум 5, максимум 50 узлов

При росте с 10 до 40 узлов RAM падает с 77 MB до 42 MB — сеть упорядочивается и освобождает память.

Ключевые метрики
Когерентность — доля валидных TEES-триад (0.95–0.998)

Температура — интегральный показатель активности (30°–45° normal)

Эритро-индекс — доля осмысленных смертей (100% у v4.1)

Разброс — разница когерентности между узлами (→ 0 при синхронизации)

Три стабильных режима
Режим	Версия	Характер
Дзен	v3.1	Редкие кризисы, быстрое восстановление
Морфогенез	v4.1	Кризисы с пользой, 100% передача энергии
Вечный Огонь	v3.3	Вечное горение в критическом режиме
Исторический контекст
Архитектура основана на наблюдениях за эритроцитами (РИД, 2016) и вихрево-топологической теории материи (РИД, 2025). Подробнее — в TEES_Chronicles.md.
