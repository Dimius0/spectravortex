## Предсказание: взаимодействие двух вихрей с одинаковым знаком заряда

**Суть:**  
Для двух вихрей с одинаковым знаком заряда (например, два протона)  
взаимодействие не сводится к простому отталкиванию, а имеет три зоны:

- **Дальняя (r > 2ξ):** притяжение (потенциал ~ 1/r³)
- **Средняя (ξ < r < 2ξ):** переходная зона — возможны равновесные точки, осцилляции
- **Ближняя (r < ξ):** сильное отталкивание, препятствующее слиянию

**Ключевое отличие от стандартной модели:**  
ВММП предсказывает, что для **нейтральных вихрей** (заряд 0, но с вихрем)  
должна существовать **равновесная точка** (связанное состояние).  
Для протонов (заряд +1) кулон сдвигает равновесие или уничтожает его.

**Метод проверки in silico:**  
- создать два компонента с зарядом +1 (протоны)  
- создать два компонента с зарядом 0, но с вихрем (нейтральные)  
- вычислить энергию системы как функцию расстояния r  
- найти минимумы (если есть)

**Критерий подтверждения:**  
- для протонов: минимум отсутствует (только отталкивание на всех r)  
- для нейтральных: есть минимум при некотором r₀
