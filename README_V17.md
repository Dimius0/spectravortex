## 🧠 ЧТО ЭТО

**Поле H** — это самоорганизующаяся среда, где смыслы:
- Резонируют (когерентность, фаза)
- Рождаются (фуркации)
- Связываются в узлы (топология)
- Живут своей жизнью (полиритмия)

**Это не поиск по ключевым словам. Это резонанс.**

### Фрактальные масштабы

| Масштаб | Что соответствует |
|---------|-------------------|
| 0.1 | буквы/символы |
| 0.3 | слоги |
| 1.0 | слова |
| 3.0 | словосочетания |

| 30.0 | абзацы |
| 100.0 | весь текст |

### Полиритмия

Каждый масштаб — отдельный кластер со своей частотой:
- Масштаб 0.1: f = 10.0
- Масштаб 0.3: f = 10.0
- Масштаб 1.0: f = 10.0
- Масштаб 3.0: f = 3.33
- Масштаб 10.0: f = 1.0
- Масштаб 30.0: f = 0.33
- Масштаб 100.0: f = 0.10

## ⚠️ ОГРАНИЧЕНИЯ

| Ограничение | Причина |
|-------------|---------|
| **Качество ответов** | Нет качественных текстов (научпоп, энциклопедии) |
| **Память** | Ноутбук, 3–4 ГБ RAM |
| **Фуркации на нижних масштабах** | Создают шум (буквы, слоги) |
| **Нет проверки истинности** | Поле не отличает правду от вымысла |
