# изома — живая система

остроена на основе математического ядра SpectraVortex.

## Структура
- core/ — C# исходники (такт, вектор, память)
- python/ — Python-обвязка для управления
- modules/ — готовые модули для анализа
- examples/ — примеры использования

## становка
pip install -r requirements.txt

## апуск
from python.rizoma import start
r = start()
