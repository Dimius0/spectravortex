# Electronegativity via Vortex Number n

## The Traditional View

Electronegativity is an empirical quantity, defined by Pauling as "the power of an atom to attract electrons to itself". It's measured experimentally, not derived from first principles.

## The VMMS View

Electronegativity is determined by the **vortex number n** — the number of local maxima of |∇H| in the nuclear configuration.

## The Rule

- **n = 0** — spherical configuration (He, Ne, Ar...)
  - Valence: 0
  - Electronegativity: low (inert gases)

- **n = 2** — octahedral configuration (O, S, Se...)
  - Valence: 2
  - Electronegativity: moderate-high

- **n = 4** — tetrahedral configuration (C, Si, Ge...)
  - Valence: 4
  - Electronegativity: moderate

- **n = 6** — cubic configuration (heavier elements)
  - Valence: variable
  - Electronegativity: depends on shell structure

## Why This Works

The vortex number n determines the number of "arms" of the vortex tube that extend from the nucleus. Each arm can form a bond. The strength of the bond (electronegativity) depends on the arm's geometry.

## Predicting Chemical Behavior

From n alone, we can predict:
- Valence (max bond count)
- Bond angles (geometry)
- Relative electronegativity (n=2 > n=4 > n=0)
- Reactivity patterns
