# Three-Axis Periodic Table + Fractal Level

## The Problem with Mendeleev's Table

The classic periodic table organizes elements by proton number (Z). But it doesn't capture:
- Why some elements have similar properties despite different Z
- The relationship between nuclear geometry and chemical behavior
- The role of the environment (pressure, temperature, field)

## Three Axes

In VMMS, elements are described by three independent coordinates:

### Axis 1: Proton Number (Z)
The number of protons — determines mass and basic identity.

### Axis 2: Vortex Number (n)
The number of local maxima of |∇H| in the nuclear configuration:
- n = 0 — spherical (He, Ne, Ar...)
- n = 2 — octahedral (O, S, Se...)
- n = 4 — tetrahedral (C, Si, Ge...)
- n = 6 — cubic (heavier elements, complex structures)

### Axis 3: Fractal Level (k)
The scale at which the element is considered:
- k = 0 — fundamental particles
- k = 1 — atomic level
- k = 2 — molecular level
- k = 3 — crystalline level
- k = 4 — biological level

## Why Three Axes?

| Axis | Reveals |
|------|---------|
| Z | Identity, mass |
| n | Bonding pattern, valence |
| k | Scale-dependent properties |

## Example: Carbon

- Z = 6
- n = 4 (tetrahedral)
- k = 1 (atomic carbon) → diamond (k=3) → graphene (k=2) → organic molecules (k=2-4)

Same element, different properties at different fractal levels.

## Predicting New Compounds

The three-axis table reveals hidden relationships:
- Elements with same n often form similar compounds
- Elements with different Z but same n can substitute in crystal structures
- Fractal level k determines which properties are relevant
