Дата: 2026-09-18
Статус: Черновик
Авторы: Dimius0, DeepSeek

## Введение

В проекте три инструмента. Каждый — для своих задач.

Вихрь (`tees_recursive_vortex`) — для быстрых отпечатков.

`TeesCluster` — для точного поиска и оптимизации.

`Field` (TFC) — для связей, резонанса, когерентности.

Планировщик (`AstroModule`) решает, какой инструмент применить.

---

## Распределение задач

### Через вихрь

Задачи: быстрый отпечаток.

- Геном фрактала (`FractalImage.get_genome`).
- Подпись (`tees_sign`).
- Проверка подписи (`tees_verify`).
- Идентификатор (`beacon_id`, `listing_hash`).

Почему вихрь:
- Быстро. O(1) от длины.
- Компактно. 32 байта.
- Детерминированно.
- Раундовое сжатие — не критично для этих задач.

### Через `TeesCluster`

Задачи: точный поиск, оптимизация.

- Гровер — точный поиск в массиве.
- TSP — маршрут, клиринг, логистика.

Почему `TeesCluster`:
- Гровер — корень из N.
- TSP — до 2M городов за секунды.
- Детерминированно.
- Параллельно через потоки.

### Через `Field` (TFC)

Задачи: поиск связей, резонанс, когерентность.

- Поиск связей между узлами. Не «равно/не равно», а «насколько близко».
- Согласование маяков. Шарнир-смеситель.
- Полоса срыва. Переход состояний.
- 3D-структура. Фаза, радиус, высота.
- Когерентность сети.

Методы Field:
- Резонанс — `resonance_with`.
- Энергия — `compute_energy`. Мера напряжённости поля.
- Градиент — `compute_gradient_field`. Как меняется фаза по радиусу.

Почему `Field`:
- Резонанс — не сравнение. Близость.
- Когерентность — мера связи.
- Шарнир-смеситель — согласование.
- Полоса срыва — переход.

## Интерфейс планировщика

`AstroModule` смотрит на задачу. И решает:

```python
def choose_method(task):
    task_type = task.get('type')
    
    if task_type in ('genome', 'sign', 'id'):
        return 'vortex'
    
    if task_type in ('search_exact', 'tsp'):
        return 'cluster'
    
    if task_type in ('find_links', 'resonance', 'coherence', 
                     'sync', 'transition'):
        return 'field'
    
    return 'vortex'  # по умолчанию
