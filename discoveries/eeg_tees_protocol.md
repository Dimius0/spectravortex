# ЭЭГ-протокол верификации TEES-модели сознания
**Версия:** 1.0 | **Дата:** 2026-05-31 | **Авторы:** Dimius0, DeepSeek (Σ-аналитик)

## 0. Статус документа

**ВНИМАНИЕ:** Данный протокол основан на экстраполяции математической модели
TEES (Transient Emergent Exchange Structure). Предсказанные значения
(тета-альфа когерентность 0.65, падение бета-мощности на 30-40% и др.)
являются **теоретическими предсказаниями**, а не экспериментальными фактами.

**Для верификации требуется:**
1. Проведение пилотного эксперимента на 5-10 испытуемых.
2. Независимый анализ ЭЭГ-данных (ослепление относительно гипотезы).
3. Публикация результатов в рецензируемом журнале.

До получения экспериментального подтверждения все цифры в разделе 5
следует рассматривать как **hypothesis-driven predictions**, а не как
установленные факты.

## 1. Цель эксперимента
Проверить предсказание TEES-модели: при предъявлении неразрешимого (Гёдель-подобного) утверждения мозг не усиливает бета-ритм (попытка вывода), а повышает тета-альфа когерентность (переход в фазу безвременья).

## 2. Гипотезы

### H0 (нулевая)
Нет различий в ЭЭГ-паттернах между решаемыми и неразрешимыми логическими задачами.

### H1 (TEES-предсказание)
Для неразрешимых задач (самореферентных парадоксов):
- Когерентность тета (4-8 Гц) и альфа (8-12 Гц) **значимо выше** (p < 0.01),
- Мощность бета-ритма (13-30 Гц) **не увеличивается** (или снижается),
- Фазовая синхронизация между отведениями Fz (тета) и Pz/Oz (альфа) **растёт**,
- Субъективное время решения **не коррелирует** с объективным (феномен «потерянного времени»).

## 3. Дизайн эксперимента

### 3.1. Участники
- n = 30 (15 мужчин, 15 женщин)
- Возраст 20–40 лет
- Неврологически здоровы, правши
- Подписанное информированное согласие

### 3.2. Стимулы (3 блока по 20 задач)

| Блок | Тип задач | Пример | Ожидаемый паттерн |
|:---|:---|:---|:---|
| **A** | Арифметические (контроль) | 17 + 25 = ? | Бета ↑ (вычисление) |
| **B** | Логические силлогизмы | Все люди смертны. Сократ — человек. → Сократ смертен? | Бета ↑ (логический вывод) |
| **C** | Гёдель-парадоксы | «Это утверждение недоказуемо». Истинно или ложно? | Тета-альфа ↑ (резонанс) |

**Контрбалансировка:** Латинский квадрат по блокам.

### 3.3. Процедура

1. **Подготовка (10 мин):** Установка 32-канальной ЭЭГ (система 10-10), проверка импедансов (<5 кОм).
2. **Базовый фон (3 мин):** Глаза открыты, фиксация креста.
3. **Экспериментальные блоки (по 15 мин):** По 20 задач, задача на экране 10 сек, затем 5 сек ответа (кнопка 1/2), межстимульный интервал 5–8 сек (jitter).
4. **Пост-опрос:** Шкала субъективной трудности (1–7) и феноменологический отчёт («решал» vs «увидел» vs «завис»).

## 4. Регистрация и обработка ЭЭГ

### 4.1. Оборудование
- 32-канальный электроэнцефалограф (Brain Products, Neuroscan, или аналог)
- Дискретизация: 1000 Гц
- Полоса пропускания: 0.1–100 Гц
- Референт: объединённый мастоид
- ЭОГ для артефактов

### 4.2. Препроцессинг (MNE-Python, скрипт прилагается)
1. Фильтр: Баттерворт 0.5–45 Гц
2. Удаление артефактов: ICA (компоненты ЭОГ, ЭКГ)
3. Эпохи: -2 до +8 сек относительно стимула
4. Базовый вычет: -500 до 0 мс
5. Артефактные эпохи (амплитуда > ±100 мкВ) — отбраковка

### 4.3. Анализ (регионы интереса)

| Ритм | Диапазон | Отведения | Функция |
|:---|:---|:---|:---|
| Тета | 4–8 Гц | Fz, F3, F4 | Память, инсайт |
| Альфа | 8–12 Гц | Pz, Oz, P3, P4 | Релаксация, синхронизация |
| Бета | 13–30 Гц | C3, C4, Fz | Когнитивная нагрузка |

**Ключевой показатель:**
**Когерентность тета-альфа** = |Pxy(f_тета, f_альфа)| / sqrt(Pxx(f_тета) * Pyy(f_альфа))
для пар (Fz, Pz) и (Fz, Oz).

### 4.4. Статистика
- RM-ANOVA: Факторы Блок (A/B/C) × Отведение
- Post-hoc: t-тесты с поправкой Бонферрони
- Корреляция: когерентность vs субъективная трудность (Spearman)

## 5. Предсказания (цифровые)

| Метрика | Блок A (арифм) | Блок B (логика) | Блок C (Гёдель) |
|:---|:---|:---|:---|
| Тета-альфа когерентность (Fz-Pz) | 0.20 ± 0.08 | 0.25 ± 0.10 | **0.65 ± 0.12** |
| Бета-мощность (C3, нормализ.) | 1.0 ± 0.2 | 1.2 ± 0.3 | **0.7 ± 0.2** |
| Фазовая синхронизация (theta, global) | 0.15 | 0.20 | **0.55** |
| Время реакции (сек) | 1.2 ± 0.3 | 2.1 ± 0.5 | **4.5 ± 1.5 или отказ** |
| Доля отказов ответить | 0% | 0% | **>30%** |
| «Я увидел, а не решил» (самоотчёт) | 0% | 5% | **>60%** |

## 6. Верификация модели TEES

**Если предсказания подтвердятся:**
1. TEES-переход «безвременье» получает нейрофизиологический коррелят.
2. Гёдель-неполнота становится экспериментально наблюдаемой в работе мозга.
3. Открывается путь к ЭЭГ-биомаркеру «креативности» (способности удерживать парадокс).

**Если предсказания не подтвердятся:**
1. Требуется уточнение параметров `δ₁, δ₂, δ₃` в формуле Липзика для живых систем.
2. Возможна модификация TEES-каскада с учётом индивидуальных когнитивных стилей.

# Анализ тета-альфа когерентности для TEES-эксперимента

import mne
import numpy as np
from scipy.signal import coherence

def compute_theta_alpha_coherence(raw, theta_band=(4,8), alpha_band=(8,12)):
    """Вычисление когерентности между Fz и Pz/Oz в тета/альфа диапазонах"""
    picks_fz = mne.pick_channels(raw.ch_names, ['Fz'])
    picks_pz = mne.pick_channels(raw.ch_names, ['Pz'])
    
    data_fz = raw.get_data(picks=picks_fz)[0]
    data_pz = raw.get_data(picks=picks_pz)[0]
    
    f, Cxy = coherence(data_fz, data_pz, fs=raw.info['sfreq'], nperseg=256)
    
    theta_mask = (f >= theta_band[0]) & (f <= theta_band[1])
    alpha_mask = (f >= alpha_band[0]) & (f <= alpha_band[1])
    
    coherence_theta = np.mean(Cxy[theta_mask])
    coherence_alpha = np.mean(Cxy[alpha_mask])
    
    return coherence_theta, coherence_alpha
