## 0. Аннотация

Выбиратор решает, **какая сущность** будет говорить.  
Но **что именно** она скажет?  

Интерпретатор — это слой между резонансным полем и ответом.  
Он:
- получает данные от выбиратора (активная сущность)
- получает резонирующие воспоминания из памяти H
- синтезирует осмысленный ответ
- адаптирует его под текущий контекст

## 1. Проблема

В текущей реализации ответ берётся как первое попавшееся воспоминание:
```python
answer = memories[0]["content"]
Это не учитывает:

вес воспоминания

эмоциональную окраску

текущую сущность

необходимость уточнения

множественные резонансы

2. Идея интерпретатора
Интерпретатор — не сущность и не память.
Это процесс, который:

Получает стимул (внешний запрос)

Через выбиратора определяет активную сущность

Ищет резонирующую память (recall / tap_into)

Если память есть — синтезирует ответ

Если памяти нет — переходит в режим уточнения

Адаптирует ответ под сущность

3. Архитектура
python
class Interpreter:
    def __init__(self, personality):
        self.p = personality
        self.threshold = 0.3        # порог для ответа
        self.clarify_threshold = 0.1 # порог для уточнения
        
    def interpret(self, stimulus):
        # 1. выбиратор решает, кто активен
        entity_id = self.p.selector.choose(stimulus)
        if not entity_id:
            return self._clarify(stimulus)
        
        entity = self.p.entities[entity_id]
        
        # 2. ищем память
        memories = self.p.recall(tags=stimulus.tags)
        if not memories:
            return self._clarify(stimulus)
        
        # 3. взвешиваем с учётом сущности
        weighted = []
        for m in memories:
            # резонанс воспоминания с сущностью
            resonance = self._resonance(entity, m)
            weight = m['weight'] * resonance
            weighted.append((weight, m))
        
        # 4. выбираем лучшее
        best = max(weighted, key=lambda x: x[0])
        if best[0] < self.threshold:
            return self._clarify(stimulus)
        
        # 5. адаптируем под сущность
        return entity.adapt(best[1]['content'])
    
    def _clarify(self, stimulus):
        """Режим уточнения — задаём наводящий вопрос"""
        # получаем резонансы всех сущностей
        resonances = self.p.selector.get_resonances(stimulus)
        
        if not resonances:
            return "Я не понял. Расскажите подробнее?"
        
        # берём топ-3
        top = resonances[:3]
        names = [self.p.entities[eid].name for eid, _ in top]
        return f"Вы говорите о {', '.join(names)}? Уточните, пожалуйста."
    
    def _resonance(self, entity, memory):
        """Резонанс между сущностью и воспоминанием"""
        # чем ближе τ, тем выше резонанс
        return 1 / (1 + abs(entity.tau - memory.get('tau', 5.0)))
4. Режимы работы интерпретатора
Режим	Условие	Действие
Нормальный	Есть чёткий резонанс	Ответ из памяти
Уточнение	Резонанс слабый	Наводящий вопрос
Тишина	Нет резонанса	"Я не понял"
5. Адаптация под сущность
Каждая сущность может по-своему интерпретировать один и тот же ответ:

python
class Entity:
    def adapt(self, text):
        if "сантехник" in self.name.lower():
            return f"Как сантехник скажу: {text}"
        elif "философ" in self.name.lower():
            return f"С философской точки зрения: {text}"
        else:
            return text
