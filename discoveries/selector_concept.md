2. Идея выбиратора
Выбиратор — это не сущность, а процесс, работающий в фоне.
Он:

получает внешний стимул

вычисляет резонанс со всеми сущностями

ведёт историю весов

применяет затухание

выбирает сущность с максимальным весом

3. Архитектура
python
class Selector:
    def __init__(self, personality):
        self.p = personality
        self.weights = {eid: 0.0 for eid in personality.entities}
        self.decay = 0.9        # затухание за шаг
        self.threshold = 0.5     # порог активации
        
    def update(self, stimulus):
        # 1. вычисляем мгновенный резонанс
        for eid, entity in self.p.entities.items():
            instant = self.resonance(stimulus, entity)
            # 2. затухание предыдущего веса
            self.weights[eid] *= self.decay
            # 3. добавляем новый вклад
            self.weights[eid] += instant * (1 - self.decay)
        
        # 4. выбираем лучшего
        best = max(self.weights.items(), key=lambda x: x[1])
        if best[1] > self.threshold:
            return best[0]
        return None
    
    def resonance(self, stimulus, entity):
        # резонанс = f(τ, имя, дефекты, контекст)
        base = 1 / (1 + abs(entity.tau - stimulus.tau))
        if stimulus.keyword in entity.name.lower():
            base += 0.3
        return base

## Что такое выбиратор

Выбиратор (Selector) — это механизм, который решает, какая сущность будет отвечать на входящий вопрос. В отличие от классических систем с одним ботом, у нас множество сущностей конкурируют за право голоса.

## Принцип работы

1. **Анализ стимула** — из вопроса извлекаются теги, предполагаемая профессия, эмоциональная окраска
2. **Резонанс** — для каждой сущности считается, насколько она подходит под вопрос
3. **Затухание** — старые темы постепенно забываются (веса умножаются на decay)
4. **Контекст** — если с сущностью уже общались, она получает бонус
5. **Выбор** — сущность с весом выше порога активируется

## Математика

```python
новый_вес = старый_вес * decay + мгновенный_резонанс * (1 - decay)
Где мгновенный_резонанс учитывает:

Спектральное совпадение τ (+2.0 × resonance)

Совпадение тегов (+2.0 за тег)

Контекст диалога (+0.2)
