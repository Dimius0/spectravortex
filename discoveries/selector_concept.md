## 0. Аннотация

В платформе «Ризома» с множественными сущностями возникает задача: **какую сущность активировать в ответ на внешний стимул?**  
Простой перебор по ключевым словам даёт грубый результат.  
Предлагается **выбиратор** — динамический резонансный механизм, имитирующий квантовый выбор на классическом железе.

2. Идея выбиратора
Выбиратор — это не сущность, а процесс, работающий в фоне.
Он:

получает внешний стимул

вычисляет резонанс со всеми сущностями

ведёт историю весов

применяет затухание

выбирает сущность с максимальным весом

3. Архитектура
python
class Selector:
    def __init__(self, personality):
        self.p = personality
        self.weights = {eid: 0.0 for eid in personality.entities}
        self.decay = 0.9        # затухание за шаг
        self.threshold = 0.5     # порог активации
        
    def update(self, stimulus):
        # 1. вычисляем мгновенный резонанс
        for eid, entity in self.p.entities.items():
            instant = self.resonance(stimulus, entity)
            # 2. затухание предыдущего веса
            self.weights[eid] *= self.decay
            # 3. добавляем новый вклад
            self.weights[eid] += instant * (1 - self.decay)
        
        # 4. выбираем лучшего
        best = max(self.weights.items(), key=lambda x: x[1])
        if best[1] > self.threshold:
            return best[0]
        return None
    
    def resonance(self, stimulus, entity):
        # резонанс = f(τ, имя, дефекты, контекст)
        base = 1 / (1 + abs(entity.tau - stimulus.tau))
        if stimulus.keyword in entity.name.lower():
            base += 0.3
        return base
4. Свойства выбиратора
Свойство	Описание
Параллелизм	Все сущности обрабатываются одновременно
Затухание	Старые темы постепенно угасают
Интерференция	Внешний стимул складывается с внутренним состоянием
Коллапс	Выбор происходит при превышении порога
Прозрачность	Можно логировать все веса
5. Связь с квантовыми процессами
Выбиратор имитирует:

суперпозицию (все сущности имеют вес)

интерференцию (стимул + история)

коллапс (выбор при пороге)

декогеренцию (затухание)

Это делает его квантово-шаговым искателем на классическом железе.
