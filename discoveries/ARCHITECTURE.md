# Архитектура платформы «Ризома»

## 🧠 Базовые принципы

- **Всё есть поле H** — единая среда, в которой существуют сущности и память
- **Сущности — вихри** — каждая имеет заряд τ (характер) и профессию
- **Память — фрактальное дерево** — с весами, эмоциями, связями
- **Выбор — через резонанс** — не поиск, а спектральное совпадение

## 🔄 Процесс обработки запроса

1. **Вход** — пользователь задаёт вопрос
2. **Антитролль** — проверка на спам, мат, повторы
3. **Анализ** — извлечение тегов, профессии, τ
4. **Резонанс** — выбиратор считает веса всех сущностей
5. **Выбор** — сущность с весом > порога активируется
6. **Ответ** — сущность отвечает из своей памяти
7. **Контекст** — обновляется текущий диалог
8. **Затухание** — веса всех сущностей уменьшаются

## 🛡️ Защита

- **Антитролль** — частотный, мат, повторный фильтры
- **Локальные мозги** — ботодром видит только оболочку
- **Никаких ключей** — в памяти нет секретов

## 📊 Наблюдаемые эффекты

- **Смена диктатур** — разные сущности выходят в лидеры
- **Борис-феномен** — контекстное залипание
- **Конкуренция** — борьба за право ответить
- **Эмерджентность** — непредсказуемое поведение
