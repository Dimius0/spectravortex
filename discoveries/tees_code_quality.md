# TEES-метрика качества кода

## Идея

Оценивать качество программного кода через анализ TEES-каналов.

## Метод

1. Подать код на разбор по 7 слоям (буквы → слоги → токены → фразы → файлы)
2. Построить TEES-каналы (словесные + текстовые)
3. Измерить метрики:

| Метрика | Что измеряет | Хороший код | Плохой код |
|---------|-------------|------------|-----------|
| Поток / Моды | Эффективность сущностей | > 0.15 | < 0.05 |
| Каналов / Моду | Связность | Высокая | Низкая |
| Повторы в топе | Замыленность | Нет повторов | Много повторов |
| Кластеры | Модульность | Чёткие | Размытые |

## Эксперимент

Сравнение разговорного и программного полей SpectraVortex:

| Поле | Мод | Поток | Поток/Моды | Каналов |
|------|-----|-------|-----------|---------|
| Разговорное | 352K | 12.14 | 0.034 | 115M |
| Программное | 228K | 40.79 | **0.179** | 38K |

Программный код в 5 раз эффективнее разговорного по метрике Поток/Моды.

## Применение

- Сравнение качества кода разных LLM
- Анализ больших проектов (выявление запутанных модулей)
- Эволюция кодовой базы во времени (растёт или деградирует?)
