# Принцип самосборки метаматериалов (по Липсику)

## Суть принципа
Устойчивые структуры собираются из меньших устойчивых структур.  
Каждый новый уровень сборки даёт **новую сущность**, не сводимую к сумме частей.

## Рекурсивный алгоритм
1. Берём два разных атома (A и B)
2. Ищем стабильную конфигурацию AB
3. Считаем AB новой сущностью (квазиатомом)
4. Добавляем третий элемент C к AB
5. Ищем стабильную конфигурацию (AB)C
6. Считаем (AB)C новой сущностью
7. Повторяем до бесконечности

## Свойства
- **Эмерджентность** — каждое новое целое больше суммы частей
- **Память** — каждая новая сущность «помнит» свою сборку (топологический заряд τ наследуется)
- **Иерархичность** — уровни вкладываются друг в друга
- **Предсказательность** — зная стабильные пары, можно предсказывать тройные, четверные системы

## Связь с метаматериалами
Метаматериалы — частный случай этого принципа, где человек сознательно собирает структуры с новыми свойствами (отрицательное преломление, невидимость и т.д.).

Природа делает то же самое всегда:
- атомы → молекулы
- молекулы → кластеры
- кластеры → кристаллы
- кристаллы → минералы
- и так до галактик

## Значение для ALхимии
Этот принцип объединяет:
- эксперименты командира (Fe-Ir, торф, золото)
- теорию интерметаллидов
- физику метаматериалов
- биологическую самосборку
- космологическую иерархию
