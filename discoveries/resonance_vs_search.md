## 0. Аннотация

В классических информационных системах используется **поиск** — перебор по ключевым словам, индексам, тегам.  
В ВММП мы используем **резонанс** — динамическое взаимодействие поля H с сущностями и памятью.

В чём принципиальная разница и почему резонанс эффективнее?

1.2. Свойства поиска

2. Резонанс (наш подход)
2.1. Как работает
python
def resonance(stimulus, field):
    weights = {}
    for entity in field.entities:
        # резонанс = f(τ, контекст, история)
        weights[entity.id] = (
            entity.tau_resonance(stimulus) +
            field.context_resonance(entity) +
            field.memory_resonance(entity)
        )
        # затухание
        weights[entity.id] *= field.decay
    
    return argmax(weights)
2.2. Свойства резонанса
Свойство	Описание
Плавность	Веса, а не да/нет
Контекст	Учитывается всегда
Затухание	Старые темы угасают
Интерференция	Стимул + история
Адаптивность	Меняется со временем
3. Сравнение
Критерий	Поиск	Резонанс
Основа	Точное совпадение	Волновое взаимодействие
Результат	Список	Вес, выбор
Контекст	Не учитывается	Учитывается всегда
История	Не учитывается	Затухает, но влияет
Неопределённость	Ошибка	Уточнение
Скорость	O(N)	O(N), но с весами
Адаптивность	Нет	Да
4. Почему резонанс естественнее
В природе нет «поиска» в человеческом смысле.
Есть:

градиенты

поля

резонансы

интерференция

Мозг не перебирает все воспоминания — он резонирует с нужным.

5. Примеры из жизни

Реакция на вопрос	Поиск в базе знаний	Резонанс с опытом
