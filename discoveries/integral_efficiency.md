# Интегральная эффективность текстового поля SpectraVortex

## Аннотация

Впервые получены количественные метрики качества кода и разговорного языка 
через анализ TEES-каналов. Обнаружено, что программный код в 5 раз эффективнее 
разговорной речи по метрике Поток/Моды. Интегральная эффективность проекта 
(код + обсуждения) составляет 0.091.

## Метод

### Разделение корпуса

Исходный корпус: 43 677 сообщений (диалоги разработчиков SpectraVortex).

Разделён на два подкорпуса:
- **Разговорное поле:** 30 773 сообщения (естественный язык, без кода)
- **Программное поле:** 12 904 сообщения (Python-код, без разговоров)

Критерии разделения: наличие маркеров кода (`def`, `import`, `class`, `self.`, `return`, `{`, `}`).

### Построение полей

Каждое поле построено по 7-слойной архитектуре:
- Слой 1: буквы
- Слой 2: слоги
- Слой 3-4: слова/токены
- Слой 5-6: фразы (устойчивые пары токенов)
- Слой 7: целые сообщения

TEES-каналы построены на основе направленных пар токенов (словесные каналы) 
и через общие фразы (текстовые каналы — потоковые, без хранения в памяти).

### Метрики

| Метрика | Формула | Что измеряет |
|---------|---------|-------------|
| Поток (Flow) | Суммарный перенос энергии за 200 циклов | Интенсивность взаимодействий |
| Поток/Моды | Flow / N_modes | Эффективность использования сущностей |
| Каналов/Моду | N_channels / N_modes | Связность |
| Текстовых каналов | Связи через общие фразы | Межтекстовая когерентность |

## Анализ

### Эффективность кода vs разговора

Программный код (0.179) в **5.3 раза** эффективнее разговорной речи (0.034) 
по метрике Поток/Моды.

**Причина:** код имеет жёсткую структуру. Связи между токенами (`def` → `return`, 
`import` → `from`) детерминированы и сильны. Разговорная речь пластична, 
допускает вариации, синонимы, повторы — поток энергии распределён шире.

### Связность

Разговорное поле имеет **115 миллионов** текстовых каналов против 38 тысяч 
словесных в программном. Это отражает природу общения: фразы повторяются 
в разных контекстах, создавая плотную сеть межтекстовых связей.

Программное поле более модульно: тексты (файлы кода) слабее связаны друг 
с другом через общие фразы, но сильнее связаны внутри себя.

### Интегральная эффективность

Значение 0.091 — это среднее между разговором и кодом. Оно отражает 
реальную природу проекта SpectraVortex: это не просто код и не просто 
обсуждения. Это **единый организм**, где идеи рождаются в разговорах 
и кристаллизуются в коде.

## Применение

1. **TEES-ревью кода:** метрика Поток/Моды как показатель качества кодовой базы
2. **Сравнение LLM:** какая модель генерирует более эффективный код
3. **Эволюция проекта:** отслеживание метрик во времени (растёт или деградирует?)
4. **Выявление запутанных модулей:** низкий поток → высокая энтропия → рефакторинг
