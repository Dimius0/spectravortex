# Рекурсивная сборка сущностей

## Суть принципа

Если конфигурация с двумя разными атомами найдена стабильной — считаем их **одной сущностью** и можем добавлять дальше.

**Важно:** составная сущность может соединяться с другой составной сущностью — и давать новую составную сущность.  
Природа не требует, чтобы складывались только «простые» элементы. Она складывает всё со всем, что стабильно.

Алгоритм:
1. A + B → AB (стабильно)
2. AB — новая сущность (квазиатом)
3. AB + C → ABC (ищем стабильность)
4. ABC — новая сущность
5. ABC + DE → ABCDE — составная + составная
6. И так до бесконечности

---

## Почему это работает

В ВММП каждая стабильная структура — это вихрь со своим топологическим зарядом τ.  
Когда два вихря соединяются и дают новый устойчивый вихрь, он наследует память о предыдущих уровнях, но ведётся как **целое**.

Неважно, из скольких частей состояли исходные вихри. Если их соединение стабильно — возникает новая сущность.

## Условие устойчивого сосуществования (вывод из первых принципов)

### 1. Исходные положения ВММП

Из Вихревой Модели Материи-Пространства:

1. **Вихревая природа** — всякая устойчивая структура есть вихрь в квантовом конденсате
2. **Принцип окон** — сущность существует только в области параметров (T, P, состав, ...), где вихрь сохраняет топологию
3. **Локальное время** — темп изменений сущности ν = k·|dE/dt|, где k зависит от буфера
4. **Память материала** — текущее состояние зависит от истории H
5. **Буфер** — способность накапливать возмущения без смены сущности

### 2. Окна и их пересечение

Каждая сущность i характеризуется **окном** W_i в пространстве параметров.

Если окна двух сущностей **не пересекаются**:
W_i ∩ W_j = ∅

они существуют в разных режимах и не влияют друг на друга.

Если окна **пересекаются**:
W_i ∩ W_j ≠ ∅

в области пересечения возможно взаимодействие.

### 3. Мера пересечения

Введём величину **overlap** ∈ [0,1] — долю пересечения окон относительно их размеров.  
Для простоты:
- overlap = 0 — окна не пересекаются
- overlap = 1 — окна совпадают полностью

### 4. Воздействие одной сущности на другую

В области пересечения сущность i создаёт **поток воздействия** на сущность j:
Φ_ij = ν_i · σ_j · overlap


где:
- ν_i — темп i-й сущности (скорость её внутренних изменений)
- σ_j — чувствительность j-й сущности к внешним воздействиям (от 0 до 1)

**Обоснование:**  
Чем быстрее меняется сущность i, тем больше возмущений она создаёт.  
Чем чувствительнее сущность j, тем сильнее она на них реагирует.  
Чем больше пересечение окон, тем интенсивнее обмен.

### 5. Буферная ёмкость с учётом памяти

Сущность j может выдержать воздействие, если оно не превышает её **буферную ёмкость**, усиленную памятью:
C_j = B_j · (1 + γ·H_j)



где:
- B_j ∈ [0,1] — буфер (способность поглощать возмущения)
- H_j ∈ [0,1] — память (нормированная история)
- γ ∈ [0,1] — вес памяти (насколько сильно прошлое влияет на устойчивость)

**Обоснование:**  
Буфер — это запас прочности. Память может этот запас увеличивать (опыт адаптации) или уменьшать (усталость, деградация).

### 6. Условие устойчивости для пары

Для того чтобы сущность j не разрушилась под воздействием i, нужно:
Φ_ij ≤ C_j

или в развёрнутом виде:
ν_i · σ_j · overlap ≤ B_j · (1 + γ·H_j)

### 7. Симметричное условие

В общем случае обе сущности влияют друг на друга.  
Система устойчива, если для **каждой пары** с пересекающимися окнами выполняется:
max( ν_i·σ_j·overlap, ν_j·σ_i·overlap ) ≤ min( B_i·(1+γ·H_i), B_j·(1+γ·H_j) )

### 8. Физический смысл

- Если воздействие слишком сильное — сущность j не успевает его скомпенсировать и разрушается (или переходит в другое состояние)
- Если буфер большой — можно выдержать более сильного соседа
- Если есть память о прошлых воздействиях — устойчивость может расти (адаптация) или падать (усталость)

### 9. Пример: лёд и вода при 0°C

| Сущность | ν | σ | B | H | γ |
|----------|---|---|---|---|---|
| Лёд | 1 | 0.5 | 0.9 | 0.1 | 0.5 |
| Вода | 10 | 0.8 | 0.2 | 0.9 | 0.5 |

Окна пересекаются только в узкой полосе у 0°C → overlap ≈ 0.05

Проверяем условие для пары лёд→вода:
ν_л·σ_в·overlap = 1·0.8·0.05 = 0.04
C_в = B_в·(1+γ·H_в) = 0.2·(1+0.5·0.9) = 0.2·1.45 = 0.29
0.04 ≤ 0.29 → ✅

Для пары вода→лёд:
ν_в·σ_л·overlap = 10·0.5·0.05 = 0.25
C_л = 0.9·(1+0.5·0.1) = 0.9·1.05 = 0.945
0.25 ≤ 0.945 → ✅

Условие выполняется, но на пределе — любое увеличение температуры (overlap → 0) или уменьшение буфера воды разрушит равновесие.

**Это и есть 0°C** — точка фазового перехода, где сосуществование возможно только в узкой полосе и при точном балансе параметров.

## Примеры рекурсивной сборки

| Уровень | Сборка | Новая сущность |
|---------|--------|----------------|
| Атомы | H + H → H₂ | Молекула водорода |
| Молекулы | H₂ + O → H₂O | Вода |
| Интерметаллиды | Fe + Ir → FeIr | Квазиатом FeIr |
| Интерметаллид + атом | FeIr + W → FeIrW | Тройной интерметаллид |
| Интерметаллид + интерметаллид | FeIr + CuRh → (FeIr)(CuRh) | Сложная фаза |
| Кристаллы | Молекулы + упаковка | Кристаллическая решётка |
| Кристалл + кристалл | Эпитаксия | Гетероструктура |

## Связь с формулой Липсика

На каждом шаге сборки мы можем оценивать стабильность новой сущности по формуле:
F(AB) = E(AB) + α·S(AB) + β·∫W·τ dt + γ·H(AB) - δ·U(def)

**Что означают параметры:**

| Символ | Что это | Простыми словами |
|--------|---------|------------------|
| **E** | Энергия связи | Насколько сильно частицы притягиваются |
| **S** | Энтропия | Сколько способов быть «почти такой же» |
| **α** | Вес энтропии | Важен ли беспорядок |
| **W** | Окно | Открыто ли окно (1 — да, 0 — нет) |
| **τ** | Время жизни | Сколько проживёт, если окно открыто |
| **∫Wτ dt** | Интеграл жизни | Сколько реально прожила |
| **β** | Вес времени | Важно ли жить долго |
| **H** | Память | Вклад истории |
| **γ** | Вес памяти | Сила влияния прошлого |
| **U(def)** | Полезность дефектов | Могут ли дефекты помочь |
| **δ** | Вес полезности | Насколько ценим полезные дефекты |

Если F минимальна — сборка удалась, можно добавлять следующий элемент (простой или составной).

---

## Итог

Рекурсивная сборка — это способ **строить сложное из простого**, но также и **сложное из сложного**, сохраняя память на каждом шаге.

Условие устойчивого сосуществования сущностей выводится из первых принципов ВММП и даёт количественный критерий: система стабильна, если для всех пар с пересекающимися окнами выполняется
ν_i·σ_j·overlap ≤ B_j·(1+γ·H_j)

(и симметричное условие).

Природа делает так всегда. Мы просто подсмотрели и записали формулами.
