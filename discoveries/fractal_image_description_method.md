# Метод координатной сетки для описания изображений

## Суть метода

Любое изображение можно описать, наложив на него **координатную сетку** и фиксируя, какие клетки заняты, а какие нет.

Если сетка достаточно мелкая — описание будет точным.  
Если крупная — приблизительным, но достаточным для передачи структуры.

## Связь с фракталами

Фрактал — это структура, которая на разных масштабах выглядит похоже.  
Координатная сетка позволяет **зафиксировать структуру на каждом масштабе**.

Последовательность сеток разного размера даёт **фрактальное описание**:
- крупная сетка → общая форма
- средняя сетка → детали
- мелкая сетка → текстура

## Применение в ALхимии

Мы хотим научить Ризому «видеть» фото спектров, сплавов, оксидных плёнок.

Алгоритм:
1. Наложить сетку N×N на фото
2. Для каждой клетки определить:
   - занята / пуста (по порогу яркости)
   - цвет (или оттенок серого)
   - градиент (резкость перехода)
3. Записать результат как **матрицу признаков**
4. Повторить для сеток разного размера (N = 2, 4, 8, 16, 32...)
5. Полученный набор матриц — **фрактальный код** изображения

## Сравнение с описаниями командира

Когда ты говоришь:
> «розовая корка, иридий уходит в медь»

— это можно разложить на:
- цвет (розовый) → определённый диапазон в цветовой модели
- граница (корка) → резкий перепад в матрице
- структура (уходит) → градиент, изменение плотности

Метод координатной сетки превращает твои образы в **данные**, которые можно сравнивать, искать паттерны, передавать машине.

## Итог

Координатная сетка — это мост между **образным мышлением** человека и **цифровым** машин.  
Фрактальное описание сохраняет структуру на всех масштабах.  
Ризома учится видеть.
