### 0. Аннотация

Документ описывает архитектуру памяти, вдохновлённую работой человеческого восприятия. Вместо хранения полных видеофайлов или массивов сенсорных данных предлагается хранить **ключевые образы (миги)**, ассоциированные с ними сенсорные слои и правила разворачивания. При воспроизведении система достраивает картину в зависимости от **луча внимания**: то, что в фокусе, прорисовывается детально; периферия — контурно и размыто. Эмоциональная значимость определяет глубину хранения и скорость забывания.

---

### 1. Проблема: хранение видео и сенсорики в цифровых системах

Современные подходы к хранению видео и мультисенсорных данных (VR/AR) страдают от избыточности:

| Подход | Принцип | Недостаток |
|--------|---------|------------|
| **Покадровое видео** | Хранятся все кадры | Гигантские объёмы |
| **Сжатие с потерями** | Удаляется «незаметное» | Нет адаптации под внимание |
| **Сенсорные записи** | Хранятся все потоки | Нет приоритизации |

**Итог:** мы храним тонны данных, но не можем быстро найти нужное и не умеем воспроизводить **как в жизни** — с фокусом, размытием, эмоциональной окраской.

---

### 2. Биологический прототип: как работает человеческая память

Человек не хранит видео в голове. Он хранит:

1. **Миги** — ключевые образы, сцены, лица (k=1)
2. **Сенсорные слои** — звуки, запахи, ощущения (k=2)
3. **Контекст** — где, когда, с кем (k=3)
4. **Эмоции** — что чувствовал (k=4)
5. **Связи** — что было до и после (k=5)

При воспоминании:
- Сначала приходит **миг** (k=1)
- Если нужно, разворачиваются детали (k=2..5)
- То, что не в фокусе, остаётся размытым
- Эмоционально важное хранится дольше

3.3. Луч внимания
python
class AttentionBeam:
    def __init__(self, focus_point, focus_radius):
        self.focus_point = focus_point      # где центр внимания
        self.focus_radius = focus_radius    # радиус детальной прорисовки
        self.blur_radius = focus_radius * 3 # радиус размытой периферии
    
    def render(self, keyframe, scene_geometry):
        """Отрисовывает сцену с учётом фокуса"""
        result = {}
        for obj in scene_geometry:
            distance = self.distance(obj.position, self.focus_point)
            if distance < self.focus_radius:
                # объект в фокусе — детально
                result[obj.id] = obj.render_full()
            elif distance < self.blur_radius:
                # периферия — контурно, ч/б, низкое разрешение
                result[obj.id] = obj.render_contour(grayscale=True, low_res=True)
            else:
                # вне поля зрения — не отрисовываем
                result[obj.id] = None
        return result
3.4. Эмоциональная фильтрация (забывание)

class EmotionalDecay:
    def __init__(self):
        self.memories = []      # список ключевых кадров
        self.decay_rate = 0.01  # скорость забывания
    
    def update(self):
        for mem in self.memories:
            # Чем ниже эмоция и чем дольше не вспоминали, тем глубже уходит
            if mem.emotion < 0.3 and mem.last_access > 30:
                mem.depth += 1
                if mem.depth > 5:
                    self.archive(mem)      # в долговременную память
                elif mem.depth > 10:
                    self.delete(mem)        # забывается
    
    def recall(self, keyframe_id):
        mem = self.find(keyframe_id)
        mem.last_access = 0
        mem.depth = 0
        return mem
3.5. Фрактальное разворачивание
python
class FractalMemory:
    def __init__(self):
        self.keyframes = {}      # миги (k=1)
        self.layers = {}         # сенсорные слои (k=2)
        self.contexts = {}       # контекст (k=3)
        self.emotions = {}       # эмоции (k=4)
        self.network = {}        # связи (k=5)
    
    def get(self, keyframe_id, depth=1):
        """Получить воспоминание с заданной глубиной"""
        result = {"glyph": self.keyframes[keyframe_id].glyph}
        if depth >= 2:
            result["sensory"] = self.layers.get(keyframe_id, {})
        if depth >= 3:
            result["context"] = self.contexts.get(keyframe_id, {})
        if depth >= 4:
            result["emotion"] = self.emotions.get(keyframe_id, 0)
        if depth >= 5:
            result["connections"] = self.network.get(keyframe_id, [])
        return result
4. Преимущества перед классическими подходами
