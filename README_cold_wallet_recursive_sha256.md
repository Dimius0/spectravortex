# SpectraVortex: Пятое взаимодействие

Холодный биткоин-кошелёк + TEES-интеллект на фрактальных хэшах.

## Быстрый старт

### Холодный кошелёк
python cold_wallet_recursive_sha256.py                    # новый кошелёк
python cold_wallet_recursive_sha256.py "ваша фраза"      # восстановить

### TEES-интеллект
python tees_mind_v5_grammar.py                            # тестовый диалог

## Принцип

Смысл = TEES-сдвиг расстояния между фрактальными хэшами.
Без нейросетей. Без обучения. Чистая математика.

## Сложность

(8! × 64!)^depth × 2^256 ≈ 10^358 операций.
